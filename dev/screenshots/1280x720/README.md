## 脱敏脚本

在 OEA 主仓库根目录执行，复用已有的 jiti 和 Node 内置模块，无新增依赖：

```bash
pnpm exec jiti scripts/redactScreenshot.ts input.png output.png
pnpm exec jiti scripts/redactScreenshot.ts input.png output.png --rect 218,572,115,32 --rect 210,645,135,25
pnpm exec jiti scripts/redactScreenshot.ts --help
```

默认遮盖矩形为 `(68, 696, 132, 20)`，坐标格式为 `(x, y, width, height)`，原点在左上角。第二条命令额外遮盖协议终端个人信息卡的用户名和 UID，对应 `003.png`。`--rect` 可重复指定，`--no-uid` 可关闭默认 UID 遮盖。输出目录须已存在，输入只支持 1280×720、8 位、非交错 RGB/RGBA PNG。
